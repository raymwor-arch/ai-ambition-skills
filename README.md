# AI Ambition Skills

Three core skills based on Felix Rieseberg's "How to be more ambitious" tutorial.

- **altitude-elevator**: Raise tasks from small steps to real outcomes.
- **depth-expert**: Apply expert methods, primary data, and bold targets.
- **range-cross-domain**: Convert nouns to verbs and borrow cross-field methods.

Each skill lives in its own folder with a SKILL.md.
